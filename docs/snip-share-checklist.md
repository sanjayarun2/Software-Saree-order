# Floating snip + Share — APK checklist

Both paths open the same qty popup and create a PENDING order on Save.

## Share (must still work)
1. WhatsApp → select address → Share → Velo
2. Qty popup → Save order
3. Order appears in Orders

## Floating snip
1. Settings → WhatsApp → enable Floating snip
2. Allow “Display over other apps” if asked; enable again if needed
3. Open WhatsApp; purple **V** bubble visible
4. Tap V → allow screen capture → drag box over address → Use
5. Qty popup with OCR text → Save order
6. Empty/bad snip → “No text found”; no order
7. Disable Floating snip → bubble gone; Share still works

## Notes
- Android APK only (not browser)
- OCR is best on clear WhatsApp typed text
- Rebuild APK after these native changes
